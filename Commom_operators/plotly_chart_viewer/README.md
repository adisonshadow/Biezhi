# Plotly Chart Viewer 算子

Plotly 图表查看器算子 - 使用 Python Plotly 库生成交互式 HTML 图表，仅用于展示，不产生输出。

## 功能特性

- 📊 **交互式图表**：使用 Plotly 生成可交互的 HTML 图表
- 🎨 **多种图表类型**：支持折线图、散点图、柱状图、面积图
- 🔧 **Python 后端生成**：在 Python 后端生成图表，前端直接渲染
- ⚙️ **简单配置**：只需配置图表类型和字段映射
- 🖱️ **交互功能**：支持缩放、平移、悬停等交互操作

## 输入数据格式

算子接受一个名为 `data` 的输入，格式为对象数组：

```json
[
  {"x": "2024-01-01", "y": 100},
  {"x": "2024-01-02", "y": 150},
  {"x": "2024-01-03", "y": 120}
]
```

## 配置参数

### chart_type (图表类型)

- **类型**: `string`
- **默认值**: `"line"`
- **可选值**:
  - `"line"` - 折线图
  - `"scatter"` - 散点图
  - `"bar"` - 柱状图
  - `"area"` - 面积图

### x_field (X轴字段)

- **类型**: `string`
- **默认值**: `"x"`
- **说明**: 指定数据中用于 X 轴的字段名

### y_field (Y轴字段)

- **类型**: `string`
- **默认值**: `"y"`
- **说明**: 指定数据中用于 Y 轴的字段名

## 工作原理

1. **Python 后端生成**：算子执行时，使用 Plotly 生成交互式 HTML 文件
2. **文件保存**：HTML 文件保存在 `preview/main.html`
3. **前端渲染**：前端自动加载并渲染生成的 HTML 文件
4. **交互功能**：用户可以在图表上进行缩放、平移、悬停等操作

## 使用示例

### 在工作流中使用

1. 将 `plotly_chart_viewer` 算子添加到工作流
2. 连接数据源到算子的 `data` 输入端口
3. 配置图表类型和字段映射
4. 执行工作流，图表会自动生成并显示在节点下方

### 数据格式示例

```python
# 示例数据
data = [
    {"x": "Jan", "y": 100},
    {"x": "Feb", "y": 150},
    {"x": "Mar", "y": 120},
    {"x": "Apr", "y": 180},
    {"x": "May", "y": 200}
]
```

## 技术实现

- **后端**: Python + Plotly（生成 HTML 文件）
- **前端**: 直接渲染生成的 HTML（使用 iframe 或直接嵌入）
- **数据流**: 算子执行时生成图表，前端加载显示

## 与前端可视化的区别

| 特性 | Python Plotly | 前端可视化 (G2/React) |
|------|---------------|----------------------|
| 生成位置 | Python 后端 | 前端浏览器 |
| 实时更新 | 需要重新执行算子 | 支持 SSE 实时更新 |
| 交互性 | 完整的 Plotly 交互功能 | 取决于前端库 |
| 性能 | 一次性生成 | 实时渲染 |
| 适用场景 | 静态图表、复杂交互 | 实时数据监控 |

## 注意事项

1. 此算子不产生输出数据，仅用于可视化展示
2. 输入数据必须是对象数组格式
3. 确保数据中包含配置的 x_field 和 y_field 字段
4. 每次执行算子都会重新生成图表文件
5. 需要安装 Plotly: `pip install plotly`
