# Data Chart Viewer 算子

数据图表查看器算子 - 使用 @antv/g2 图表库可视化数据，仅用于展示，不产生输出。

## 功能特性

- 📊 支持多种图表类型：折线图、柱状图、面积图
- 🔄 实时数据更新：通过 SSE 实时接收数据更新
- ⚙️ 简单配置：只需配置图表类型和字段映射
- 🎨 基于 G2：使用 AntV G2 5.0 强大的图表库

## 输入数据格式

算子接受一个名为 `data` 的输入，格式为对象数组：

```json
[
  {"x": "2024-01-01", "y": 100},
  {"x": "2024-01-02", "y": 150},
  {"x": "2024-01-03", "y": 120}
]
```

## 配置参数

### chart_type (图表类型)

- **类型**: `string`
- **默认值**: `"line"`
- **可选值**:
  - `"line"` - 折线图
  - `"column"` - 柱状图
  - `"area"` - 面积图

### x_field (X轴字段)

- **类型**: `string`
- **默认值**: `"x"`
- **说明**: 指定数据中用于 X 轴的字段名

### y_field (Y轴字段)

- **类型**: `string`
- **默认值**: `"y"`
- **说明**: 指定数据中用于 Y 轴的字段名

## 使用示例

### 在工作流中使用

1. 将 `data_chart_viewer` 算子添加到工作流
2. 连接数据源到算子的 `data` 输入端口
3. 配置图表类型和字段映射
4. 执行工作流，图表会自动显示在节点下方

### 数据格式示例

```python
# 示例数据
data = [
    {"x": "Jan", "y": 100},
    {"x": "Feb", "y": 150},
    {"x": "Mar", "y": 120},
    {"x": "Apr", "y": 180},
    {"x": "May", "y": 200}
]
```

## 技术实现

- **后端**: Python 算子（仅用于数据传递，不产生输出）
- **前端**: React + @antv/g2 + data-visualization-js-sdk
- **数据流**: 通过 SSE 实时推送数据更新

## 注意事项

1. 此算子不产生输出，仅用于可视化展示
2. 输入数据必须是对象数组格式
3. 确保数据中包含配置的 x_field 和 y_field 字段
4. 图表会自动适应容器大小
