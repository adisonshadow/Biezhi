## 1. 工作流管理

### 1.1 工作流列表页面 (WorkflowList)

#### 1.1.1 页面布局
- **布局方式**: Card 网格布局（类似 ComfyUI 的工作流列表）
- **每行显示**: 3-4 个工作流卡片
- **卡片尺寸**: 响应式，适配不同屏幕

#### 1.1.2 工作流卡片 (WorkflowCard)
每个卡片显示：
- **工作流名称**: 标题，可点击进入设计器
- **工作流描述**: 简短描述（可选）
- **工作流版本**: 版本号
- **创建时间**: 创建日期
- **最后修改时间**: 最后修改日期
- **状态标识**: 
  - 已部署（有执行任务）
  - 未部署
  - 有错误（验证失败）
- **操作按钮**:
  - 打开设计器（主要操作）
  - 导出工作流
  - 删除工作流
  - 更多操作（下拉菜单）

#### 1.1.3 页面工具栏
- **创建新工作流**按钮: 打开创建对话框
- **导入工作流**按钮: 支持导入 JSON/YAML 格式
- **设置按钮**: 打开设置面板（大模型配置等）
- **搜索框**: 按名称、描述搜索
- **筛选器**: 
  - 按分类筛选
  - 按标签筛选
  - 按状态筛选（已部署/未部署）
- **排序**: 按创建时间、修改时间、名称排序
- **视图切换**: 卡片视图 / 列表视图

#### 1.1.4 功能操作

**创建工作流**
- 点击"创建新工作流"按钮
- 弹出创建对话框
- 必填字段：
  - 工作流名称
- 可选字段：
  - 描述
  - 版本号（默认 1.0.0）
  - 作者
  - 分类
  - 标签
- 创建后自动跳转到工作流设计器

**编辑工作流**
- 在工作流卡片上点击"编辑"或直接点击卡片标题
- 跳转到工作流设计器页面
- 支持在工作流设计器中编辑基本信息

**删除工作流**
- 点击卡片上的"删除"按钮
- 弹出确认对话框
- 删除前检查是否有关联的执行任务
- 如果有执行任务，提示用户先删除执行任务

**导入工作流**
- 点击"导入工作流"按钮
- 支持两种导入方式：
  - 上传文件（JSON/YAML）
  - 粘贴 JSON 内容
- 导入后验证工作流格式
- 验证通过后创建新工作流
- 导入失败显示错误信息

**导出工作流**
- 在工作流卡片上点击"导出"按钮
- 导出格式：JSON（包含完整配置）
- 下载文件：`{workflow_name}_{version}.json`

**节点显示内容**

  - 未配置（灰色）

  - 配置错误（红色）
  - 执行中（蓝色动画）
  - 执行成功（绿色）
  - 执行失败（红色）

**节点设计参考**
- 参考旧项目 `/Users/yanfang/dev/flowdata/web/src/components/CustomNode.tsx`
- 节点结构：
  - **Header区域**: 显示节点名称、类型标签（Badge）、状态指示器、操作菜单（三点菜单）
  - **端口区域**: 左侧输入端口列表，右侧输出端口列表，每个端口显示端口名称
  - **配置/预览区域**: 可折叠的 Accordion 面板
    - 配置面板：显示节点配置参数（表格形式）
    - 预览面板：显示输出数据预览

  - 旧项目使用 Mantine UI，新项目使用 Ant Design
  - 需要将 Mantine 组件替换为对应的 Ant Design 组件：
    - `Box` → `div` + Ant Design 样式
    - `Group` → `Space` 或 `Flex`
    - `Text` → `Typography.Text`
    - `Badge` → `Tag`
    - `ActionIcon` → `Button` (icon only)
    - `Menu` → `Dropdown`
    - `Accordion` → `Collapse`
    - `Table` → `Table`
    - `TextInput` → `Input`
    - `Checkbox` → `Checkbox`
- **保持功能**:
  - 节点选中状态样式（边框高亮）
  - 右键菜单功能（复制、查看日志、删除等）
  - 端口连接功能
  - 配置和预览面板的折叠展开

#### 1.2.5 工作流完备性自动检查

**检查时机**
- 节点添加/删除时
- 连接创建/删除时
- 节点配置修改时
- 手动触发验证

**检查内容**
- **节点检查**:
  - 所有节点是否关联有效的算子
  - 节点配置是否完整
  - 必需参数是否已填写
- **连接检查**:
  - 连接是否有效（节点存在）
  - 端口类型是否匹配
  - 是否存在循环依赖
  - 是否存在孤立节点
- **图完整性检查**:
  - 是否存在入口节点（无输入的节点）
  - 是否存在出口节点（无输出的节点）
  - 图是否连通

**显示方式**
- 工具栏状态指示器
- 画布上错误节点/连接高亮显示
- 右侧验证结果面板（可展开/收起）
- 错误/警告列表，点击定位到对应节点

#### 1.2.6 AI对话面板 (AIChatPanel)

**功能**
- 与AI对话创建新算子
- 基于自然语言描述生成算子配置
- 支持对话式迭代优化算子

**界面布局**
- 对话历史区域（可滚动）
- 输入框（支持多行）
- 发送按钮
- 清除对话按钮

**对话流程**
1. 用户描述需求（如："创建一个数据过滤算子，可以按列名和值过滤DataFrame"）
2. AI生成算子配置建议
3. 用户确认或提出修改意见
4. AI调整配置
5. 用户确认后，AI创建算子并添加到画布

**显示内容**
- 用户消息（右侧）
- AI回复（左侧）
- 算子配置预览（可编辑）
- 确认/取消按钮

#### 1.2.7 调试控制台 (DebugConsole)

**功能**
- 显示工作流执行过程中的调试信息
- 显示节点执行日志
- 显示数据流信息
- 支持断点调试（未来功能）

**界面布局**
- 标签页：
  - 日志 (Logs)
  - 数据 (Data)
  - 性能 (Performance)
- 日志级别筛选：All / Debug / Info / Warning / Error
- 搜索框：搜索日志内容
- 清除按钮：清除控制台内容
- 自动滚动开关

**显示内容**
- 时间戳
- 日志级别（带颜色）
- 节点ID/名称
- 日志消息
- 数据快照（可展开查看）

## 2. 执行任务管理

### 2.1 执行任务列表页面 (ExecutionList)

#### 2.1.1 页面布局
- **布局方式**: 表格列表
- **显示模式**: 列表视图（默认）/ 卡片视图（可选）

#### 2.1.2 表格列
- **任务ID**: 可点击查看详情
- **工作流名称**: 显示关联的工作流名称（可点击跳转到工作流）
- **状态**: 
  - 等待中 (pending) - 灰色
  - 运行中 (running) - 蓝色（带动画）
  - 成功 (success) - 绿色
  - 失败 (failed) - 红色
  - 已取消 (cancelled) - 橙色
- **创建时间**: 任务创建时间
- **开始时间**: 任务开始执行时间
- **完成时间**: 任务完成时间
- **持续时间**: 执行时长（运行中显示已运行时长）
- **进度**: 运行中显示进度条（如果支持）
- **操作**: 
  - 查看详情
  - 启动（pending状态）
  - 暂停（running状态）
  - 停止（running状态）
  - 删除

#### 2.1.3 页面工具栏
- **创建执行任务**按钮: 选择工作流创建新任务
- **批量操作**: 
  - 批量启动
  - 批量停止
  - 批量删除
- **筛选器**:
  - 按状态筛选
  - 按工作流筛选
  - 按时间范围筛选
- **搜索框**: 按任务ID、工作流名称搜索
- **刷新按钮**: 手动刷新列表
- **自动刷新开关**: 定时刷新（默认关闭）

#### 2.1.4 功能操作

**创建执行任务**
- 点击"创建执行任务"按钮
- 弹出对话框：
  - 选择工作流（下拉选择或搜索）
  - 输入任务名称（可选）
  - 输入输入数据（JSON格式，可选）
- 创建后任务状态为 pending
- 可选择立即启动或稍后启动

**启动任务**
- 单个启动：点击任务行的"启动"按钮
- 批量启动：选择多个pending状态的任务，点击"批量启动"
- 启动后状态变为 running

**暂停任务**
- 点击任务行的"暂停"按钮
- 暂停后状态变为 paused（需要API支持）
- 可恢复执行

**停止任务**
- 点击任务行的"停止"按钮
- 弹出确认对话框
- 停止后状态变为 cancelled

**删除任务**
- 单个删除：点击任务行的"删除"按钮
- 批量删除：选择多个任务，点击"批量删除"
- 删除前确认
- 运行中的任务需要先停止才能删除

- **资源使用统计**（如果API提供）:
  - CPU使用率
  - 内存使用量

## 7. API接口需求

### 7.1 工作流相关
- ✅ `GET /api/workflows` - 获取工作流列表
- ✅ `POST /api/workflows` - 创建工作流
- ✅ `GET /api/workflows/:id` - 获取工作流详情
- ✅ `PUT /api/workflows/:id` - 更新工作流
- ✅ `DELETE /api/workflows/:id` - 删除工作流
- ✅ `POST /api/workflows/:id/validate` - 验证工作流
- ✅ `GET /api/workflows/:id/execution-order` - 获取执行顺序
- ⚠️ `POST /api/workflows/import` - 导入工作流（需要新增）
- ⚠️ `GET /api/workflows/:id/export` - 导出工作流（需要新增）

### 7.2 执行任务相关
- ✅ `GET /api/executions` - 获取执行任务列表
- ✅ `POST /api/executions` - 创建执行任务
- ✅ `GET /api/executions/:id` - 获取执行任务详情
- ✅ `POST /api/executions/:id/start` - 启动任务
- ✅ `POST /api/executions/:id/stop` - 停止任务
- ✅ `DELETE /api/executions/:id` - 删除任务
- ✅ `GET /api/executions/:id/logs` - 获取执行日志
- ⚠️ `POST /api/executions/:id/pause` - 暂停任务（需要新增）

### 7.3 算子相关
- ✅ `GET /api/operators` - 获取算子列表
- ✅ `GET /api/operators/:id` - 获取算子详情
- ⚠️ `POST /api/operators/ai-create` - AI创建算子（需要新增）

### 7.4 日志分析相关
- ⚠️ `GET /api/logs` - 获取日志列表（支持筛选）（需要新增）
- ⚠️ `GET /api/logs/analysis` - 获取日志分析结果（需要新增）

## 8. 注意事项

1. **性能考虑**:
   - 工作流列表使用虚拟滚动（如果数据量大）
   - 画布节点数量限制（建议不超过100个节点）
   - 日志列表使用分页加载

2. **用户体验**:
   - 所有操作提供加载状态
   - 错误信息友好提示
   - 操作确认对话框（删除、停止等）
   - 自动保存草稿（工作流设计器）

3. **响应式设计**:
   - 移动端适配（基础功能）
   - 平板适配
   - 桌面端完整功能

4. **可访问性**:
